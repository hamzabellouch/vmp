# Privacy Policy - VMP

Last Updated: September 8, 2026


### 1. Executive Summary & Overview:

VMP (Video Max Player) is an ultra-native, high-performance video player and benchmarking suite for Linux OS, engineered in C++20 for high-bitrate video playback (up to 4K / 8K / 16K) with hardware acceleration and microsecond-accurate audio synchronization.

#### Core Privacy Commitment:
VMP operates **100% offline and on-device**. We do not collect, store, transmit, track, share, or sell any personal data, media files, playback logs, device identifiers, or system telemetry to external analytics servers or third parties.


### 2. Information Processed On-Device:
To deliver video playback, post-processing shaders, and performance benchmarking, VMP reads and processes the following information `strictly locally on your machine`:

- **Local Video & Audio Streams:** Video containers, audio tracks, and external subtitle files (`.srt`, `.vtt`) opened by the user are decoded in volatile memory (RAM / GPU VRAM) solely for real-time presentation. No media data is ever uploaded, copied, or transmitted.
- **Playback Resume History:** Minimal playback timestamps and file paths are stored locally on your device (in `~/.config/vmp/` or user home cache) strictly to allow resuming video playback from where you left off.
- **Session Telemetry & Benchmarks:** Performance metrics (active FPS, 1% Low FPS, per-frame latency in ms, bitrate) are rendered on-screen via the built-in HUD (`T`) and are only exported to local disk files when explicitly requested by the user via `--export-stats <file.json>`.
- **Application Preferences:** User settings (such as active shader filter, audio volume, and fullscreen state) are maintained locally during execution.


### 3. System Resources & Access Scope:
VMP accesses specific Linux system resources strictly to deliver its core media functionality:

**A. Local File System Access**
- **Purpose:** Opens and reads video files, audio streams, and subtitle files chosen by the user via command-line arguments, file dialogs, or drag-and-drop actions.
- **Scope:** Read-only access to specified media files. VMP does not scan or index unauthorized directories.

**B. GPU Hardware Acceleration & OpenGL** (`/dev/dri/renderD*`, VA-API, NVDEC/CUDA)
- **Purpose:** Utilizes your graphics card for hardware-accelerated video decoding and GLSL post-processing shader rendering.
- **Scope:** Direct hardware access bounded by user-space driver interfaces. No GPU buffer data is retained or extracted.

**C. Audio Device Output** (SDL2 / ALSA / PulseAudio / PipeWire)
- **Purpose:** Delivers synchronized, low-latency audio playback to your default system audio output.
- **Scope:** Output-only audio streaming; VMP contains zero microphone or audio recording capabilities.

**D. Zero Network / Internet Access**
- **Purpose:** VMP is built with no networking or socket dependencies.
- **Scope:** The application does not connect to the internet, make HTTP requests, or communicate with remote servers.


### 4. Video Processing & Hardware Decoder Safety Policy:
VMP complies fully with privacy guidelines and local execution security:

- **Strict Video-Only Isolation:** Static image formats and non-video payload files are intentionally rejected upon launch with exit code `1` to protect desktop MIME type associations and prevent malicious file parser exploits.
- **Zero Background Activity:** VMP operates only when actively launched by the user and terminates all CPU/GPU threads immediately upon window closure or CLI process exit.
- **Root-Free Execution:** VMP runs entirely in unprivileged user space and does not require `sudo` or `root` permissions for normal playback or benchmarking.


### 5. Data Sharing, Analytics & Advertising:

- **No Data Sharing:** No media contents, file paths, or telemetry metrics ever leave your machine.
- **No Third-Party Analytics / Tracking:** VMP contains no embedded analytics SDKs, telemetry beacons, or crash reporters.
- **No Advertisements:** VMP is completely free, open-source, and does not display any advertisements or sponsored content.


### 6. Data Retention & Lifecycle:

- **Volatile Buffer Wiping:** Decoded video frames in the ring buffer and GPU texture memory are cleared from RAM and VRAM immediately upon stream completion, pause, or application exit.
- **Complete Data Removal:** Uninstalling VMP and deleting `~/.config/vmp/` permanently removes all application shortcuts, icons, and saved playback timestamps.


### 7. Managing Data & User Rights:
You maintain total control over all local data generated by VMP:

**A. View Saved Playback Timestamps:**
```bash
vmp_cli resume --list
```

**B. Clear All Playback Resumption History:**
```bash
vmp_cli resume --clear
```

**C. Remove All Application Files & Cache:**
```bash
rm -rf ~/.config/vmp ~/.local/bin/vmp_engine ~/.local/bin/vmp_cli ~/.local/share/applications/vmp.desktop
```

# سياسة الخصوصية - VMP
آخر تحديث: ٨ سبتمبر ٢٠٢٦

### ١. الملخص التنفيذي والنظرة العامة:

مشغل VMP (Video Max Player) هو مشغل فيديو وأداة قياس أداء فائقة السرعة مخصصة لأنظمة Linux، ومبنية بلغة C++20 لتشغيل مقاطع الفيديو ذات معدلات البت العالية (حتى 4K / 8K / 16K) مع تسريع عتادي وتزامن صوتي فائق الدقة.

#### الالتزام الأساسي بالخصوصية:
يعمل VMP **بنسبة ١٠٠٪ دون اتصال بالإنترنت ومحلياً على جهازك**. نحن لا نجمع أو نخزن أو ننقل أو نتتبع أو نشارك أو نبيع أي بيانات شخصية، أو ملفات وسائط، أو سجلات تشغيل، أو معرفات أجهزة، أو بيانات قياس الأداء إلى أي خوادم خارجية أو أطراف ثالثة.


### ٢. المعلومات التي تتم معالجتها محلياً على الجهاز:
لتقديم تشغيل الفيديو، وشيدرات المعالجة البصرية، واختبارات الأداء، يقوم VMP بقراءة ومعالجة البيانات التالية **بشكل محلي تماماً على جهازك**:

* **تدفقات الفيديو والصوت المحلية:** يتم فك ترميز ملفات الفيديو ومسارات الصوت وملفات الترجمة الخارجية (`.srt`, `.vtt`) التي يفتحها المستخدم داخل الذاكرة المؤقتة (RAM / GPU VRAM) فقط من أجل العرض المباشر. لا يتم نسخ أو رفع أو إرسال أي ملفات وسائط مطلقاً.
* **سجل استئناف التشغيل:** يتم حفظ طوابع زمنية بسيطة ومسارات الملفات محلياً على جهازك (في دليل `~/.config/vmp/`) لتمكينك من استئناف تشغيل الفيديو من النقطة التي توقفت عندها.
* **بيانات القياس عن بعد والاختبار (Telemetry):** يتم عرض مؤشرات الأداء (معدل الإطارات الفعلي FPS، وأدنى إطارات 1% Low، وزمن استجابة الإطار بالمللي ثانية، ومعدل البت) على الشاشة عبر واجهة HUD المدمجة (`T`)، ولا يتم تصديرها إلى ملفات على القرص إلا إذا طلب المستخدم ذلك صراحةً عبر الأمر `--export-stats <file.json>`.
* **تفضيلات التطبيق:** يتم الاحتفاظ بإعدادات المستخدم (مثل فلتر الشيدر النشط، ومستوى الصوت، ووضع ملء الشاشة) محلياً أثناء الجلسة.


### ٣. موارد النظام ونطاق الوصول:
يصل VMP إلى موارد محددة في نظام Linux حصرياً لتقديم وظائفه الأساسية:

**أ. الوصول إلى نظام الملفات المحلي**
* **الغرض:** فتح وقراءة ملفات الفيديو وتدفقات الصوت وملفات الترجمة التي يختارها المستخدم عبر سطر الأوامر أو مربعات الحوار أو خاصية السحب والإفلات.
* **النطاق:** وصول للقراءة فقط للملفات المحددة، دون مسح أو فحص مجلدات غير مصرح بها.

**ب. التسريع العتادي عبر كرت الشاشة وOpenGL** (`/dev/dri/renderD*`, VA-API, NVDEC/CUDA)
* **الغرض:** استخدام كرت الشاشة لفك ترميز الفيديو عتادياً ومعالجة الشيدرات في الوقت الفعلي.
* **النطاق:** وصول مباشر مقيد بواجهات تعريفات المستخدم، دون استخراج أو تخزين بيانات بطاقات الرسوميات.

**ج. إخراج الصوت** (SDL2 / ALSA / PulseAudio / PipeWire)
* **الغرض:** تشغيل تدفقات الصوت بدقة وتزامن مع مكبرات الصوت أو السماعات.
* **النطاق:** تدفق إخراج صوتي فقط؛ لا يحتوي VMP على أي إمكانية للوصول إلى الميكروفون أو تسجيل الصوت.

**د. انعدام الاتصال بالشبكة والإنترنت تماماً**
* **الغرض:** تم بناء المشغل بدون أي مكتبات أو مقابس شبكية.
* **النطاق:** لا يتصل التطبيق بالإنترنت ولا يرسل أي طلبات HTTP ولا يتواصل مع خوادم خارجية.


### ٤. سياسة أمان فك الترميز ومعالجة الفيديو:
يلتزم VMP التزاماً كاملاً بمعايير الأمان والخصوصية:

* **عزل حصري للفيديو:** يتم رفض ملفات الصور الثابتة والملفات غير المتوافقة فوراً برمز الخروج `1` لمنع تجاوز التطبيقات الافتراضية وحماية النظام من ثغرات الملفات الخبيثة.
* **انعدام النشاط في الخلفية:** يعمل VMP فقط عند تشغيله الفعلي من قبل المستخدم، ويغلق كافة الخيوط والمعالجات بمجرد إغلاق النافذة أو إنهاء أمر CLI.
* **العمل دون صلاحيات Root:** يعمل المشغل بكافة ميزاته في مساحة المستخدم العادية دون طلب أي صلاحيات إدارية أو `sudo`.


### ٥. مشاركة البيانات، التحليلات والإعلانات:

* **عدم مشاركة البيانات:** لا تغادر أي بيانات أو وسائط أو مسارات ملفات جهازك على الإطلاق.
* **عدم وجود تتبع أو تحليلات من طرف ثالث:** لا يحتوي VMP على أي حزم تتبع أو أدوات مراقبة أو برمجيات لجمع التقارير.
* **خالٍ من الإعلانات:** التطبيق مجاني بالكامل ومفتوح المصدر وخالٍ من أي إعلانات أو محتوى ترويجي.


### ٦. دورة حياة البيانات والاحتفاظ بها:

* **مسح الذاكرة المؤقتة:** يتم مسح كافة الإطارات المفكوكة وذاكرة كرت الشاشة فور إيقاف التشغيل أو إغلاق التطبيق.
* **الحذف الكامل للبيانات:** يؤدي إلغاء تثبيت VMP وحذف مجلد الإعدادات `~/.config/vmp/` إلى إزالة كافة الاختصارات والتفضيلات وسجلات الاستئناف نهائياً من النظام.
